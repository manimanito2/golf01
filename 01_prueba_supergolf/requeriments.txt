Stack Tecnológico

1. Backend
Lenguaje: Python 3.13
Framework principal: Flask
Manejo de rutas y vistas con Blueprints
Sistema de plantillas con Jinja2
Mensajería de usuario con flash()
Controladores modulares (main_controller, player_controller, match_controller)

2. Base de Datos
SQLite — Base de datos ligera y embebida
Archivo principal: instance/golf.db
ORM: SQLAlchemy
Modelos definidos: Player, Match, Press
Operaciones CRUD mediante db.session

3.Frontend
HTML5 — Plantillas (home.html, list_players.html, etc.)
CSS3 — Estilos personalizados (static/css/style.css)
Jinja2 — Motor de plantillas de Flask ({% extends 'base.html' %}, {{ variable }})
JavaScript — Interactividad básica (static/js/interacciones.js)

4. Arquitectura del Proyecto
Estructura basada en el patrón MVC (Modelo - Vista - Controlador):
